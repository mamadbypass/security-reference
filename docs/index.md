## Sections

### Offensive Security
- **Bug Bounty** — Recon, subdomain enumeration, port scanning, tech detection
- **Web** — SQLi, XSS, SSRF, IDOR, SSTI, smuggling, cache poisoning, and more
- **API** — GraphQL, versioning, shadow APIs, gRPC
- **Authentication** — JWT, SSO/SAML, password reset, WebAuthn
- **Mobile** — APK/IPA analysis, Frida, SSL pinning, deep links
- **Network** — Active Directory, privilege escalation, lateral movement
- **Cloud** — AWS, Azure, GCP, Kubernetes
- **Binary** — Reverse engineering, stack/heap exploitation
- **Web3** — Smart contracts, wallet/dApp security

### Defensive Security
- **Blue Team** — Detection engineering, SIEM, threat hunting, IR
- **Forensics** — Disk, memory, network, and cloud forensics
- **Secure Code Review** — SAST, manual review, threat modeling

### Supporting Topics
- **Cryptography** — TLS, padding oracle, crypto flaws
- **Containers** — Docker, Kubernetes hardening, container escape
- **DevSecOps** — CI/CD, IaC, supply chain security
- **OSINT** — People/org research, breach search
- **Social Engineering** — Phishing, pretexting (authorized only)
- **IoT** — Firmware and hardware interface analysis
- **Growth** — CVE research, writeups, reputation building
- **Reporting** — Vulnerability report writing
