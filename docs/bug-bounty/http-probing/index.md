# HTTP Probing

Identify live web services, technologies, and response behaviors.

## Methodology

- [ ] Probe HTTP/HTTPS on discovered hosts
- [ ] Capture status codes, titles, and redirects
- [ ] Detect WAF and CDN behavior
- [ ] Build a prioritized target list

## Tools

- `httpx`
- `httprobe`
- `aquatone`
- `gowitness`
